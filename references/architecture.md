## 2. 情感分类策略（省 Token 核心）

### 三层过滤架构

```
              全部搜索结果
                  │
         ┌───────▼───────┐
         │  Layer 1      │  SnowNLP 本地分类
         │  7.7MB, 280条/s│  零 token 消耗
         │  正面/负面/不确定│
         └──┬───────┬────┘
            │       │
     确定(60-80%)   │ 不确定(20-40%)
            │       │
            │  ┌────▼────┐
            │  │ Layer 2 │  LLM 精判
            │  │ 仅处理   │  消耗 token
            │  │ 不确定项  │  但量很少
            │  └────┬────┘
            │       │
            ▼       ▼
         ┌──────────────┐
         │  Layer 3     │  预警关键词检查
         │  纯本地匹配   │  零 token
         │  四色预警判定  │
         └──────────────┘
```

### SnowNLP 阈值设计

| 条件 | 判定 | 置信度 | LLM? |
|------|------|--------|------|
| score > 0.70 | 正面 | 高 | 否 |
| score < 0.30 | 负面 | 高 | 否 |
| 0.30 ≤ score ≤ 0.70 | 中性/不确定 | 低 | **是** |

**设计理由**：
- 漏判负面比误判中性更危险 → 负阈值收紧到 0.30
- 中性文本被归为正面不影响预警 → 正阈值放宽到 0.70
- 中性被误判为负面 → Layer 3 预警关键词检查会自动降级

### 实测表现

| 类别 | 准确率 | 说明 |
|------|--------|------|
| 正面 | 100% | 4/4 全对 |
| 负面 | 100% | 4/4 全对 |
| 中性 | 0% | 全被误判为正/负面，但不影响预警 |

## 3. 四色预警体系

```
蓝色 (blue)   ──→  黄色 (yellow)  ──→  橙色 (orange)  ──→  红色 (red)
  低热度负面        同类负面2+条        处罚/违法/造假       热搜/封杀/刑拘
  纳入日报          权威媒体负面        产品质量/监管介入     停业/吊销/逮捕
                   热度 >= 6          法律纠纷/败诉
```

升级规则：
- **蓝色**: 默认，所有低热度负面
- **黄色**: 同一话题 2+ 条负面，或热度分 ≥ 6
- **橙色**: 包含严重负面关键词，或来源为高权威媒体
- **红色**: 包含红色预警关键词（热搜、封杀、停业等）

降级保护：
- 中性文本被 SnowNLP 误判为负面时，预警关键词检查不含严重词 → 自动降为蓝色或不预警
- 避免虚假预警

## 4. 热度评分算法

```
heat_score = platform_weight × rank_score × freshness
```

| 因素 | 取值 | 说明 |
|------|------|------|
| platform_weight | 1-3 | 微博/小红书/知乎=3, 新闻门户=2, 搜索引擎=1 |
| rank_score | 1-3 | 前3名=3, 4-6名=2, 7+=1 |
| freshness | 0.5-3 | 当天=3, 3天内=2, 7天内=1, 更早=0.5 |

## 5. 去重策略

两轮去重：
1. **内容指纹**: MD5(标题 + 摘要前30字 + URL) 取前12位
2. **编辑距离**: 标题相似度 ≥ 0.8 视为重复

## 6. 趋势追踪

- 每次报告记录：正/负/中性数量、预警等级、时间戳
- 保留最近 30 条记录
- 趋势对比：当前 vs 上次报告的增减量
- 异常检测：连续 3 次报告负面数量上升 → 触发警告
